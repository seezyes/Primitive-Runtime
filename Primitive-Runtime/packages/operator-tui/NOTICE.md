# Operator panel source attribution

The terminal palette, frame-diff renderer, keyboard/mouse decoder and viewport
helpers are adapted from the repository owner's `tui-mockup-src.zip`, supplied
for this project on 2026-10-21.

Source archive SHA-256:
`1a5459af7b185ef1d17fd735920726ff68064d411a1152267636ad84620ecafa`.

Adapted source modules: `src/core/tui.mjs`, `src/core/input.mjs`, and
`src/core/listview.mjs`. The original placeholder screens, mock actions,
arbitrary plugin loader, external account fixtures and console-changing
PowerShell scripts are not used. The operator forms, authenticated service
adapter boundary and terminal-output sanitization are part of Primitive
Runtime.
